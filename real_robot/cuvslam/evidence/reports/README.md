# Real-camera reports

Store RealSense D435i/cuVSLAM experiment conclusions and acceptance reports
here. Reports must identify the hardware, firmware, Jetson/ROS environment,
parameters, route, metrics, evidence paths, failures, and conclusion.

This directory is separate from
`../../../../simulation/cuvslam/evidence/reports/`: simulation evidence cannot
be used as real-camera accuracy evidence. Preserve failed runs and do not
rewrite a report to make a later result pass.
