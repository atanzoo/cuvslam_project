# Research records

Research records are separated from executable workspaces and acceptance
evidence.

- `cuvslam/` contains cuVSLAM hypotheses, experiment plans, and cross-run
  research notes.
- `path_planning/` contains D1 Edu/PPO/IMM/MPPI research records.
- `papers/` contains reference material.
- Future cuVSLAM and RPLIDAR research notes should use explicit workstream
  subdirectories and link to the corresponding evidence directory.

Each experiment record should state its hypothesis, environment, hardware,
software versions, parameters, procedure, metrics, evidence path, conclusion,
and next step.
