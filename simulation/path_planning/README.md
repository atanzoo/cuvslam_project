# Path-planning simulation

This directory contains the independent D1 Edu/path-planning simulation:
robot description, curated 2D maps, trajectory tools, PPO/IMM/MPPI research
code, and navigation evaluation helpers.

It is not evidence of D1 Max hardware behavior and is not the cuVSLAM
simulation runtime. Future RPLIDAR/Nav2 simulation work belongs here unless it
is specifically a cuVSLAM sensor-contract experiment.
