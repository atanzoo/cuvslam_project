# Simulation reports

Store cuVSLAM Gazebo/replay experiment reports and acceptance reports here. A
report must state the environment, configuration, data source, metrics,
failures, and conclusion.

These reports are valid for estimator, ROS contract, and observability history
only. They must not be presented as RealSense accuracy. Real D435i reports are
stored separately under
`../../../../real_robot/cuvslam/evidence/reports/`, with runtime logs under
`../../../../real_robot/cuvslam/evidence/logs/`.

Do not replace a failed report with a successful rerun. Preserve both and link
the rerun to the original experiment.
